DRONE–SENTINEL//WEB FLASHER//LEVEL 2
Preview build, not a published release
Installabout 1 minute per board
1

Use Chrome or Edge on a computer

Flashing from a web page needs Web Serial: Chrome, Edge or Opera on Windows, macOS, Linux or ChromeOS. Firefox, Safari and phones can't do it.

2

Plug the XIAO in

Use a USB-C data cable: charge-only cables never show up as a port. On a field station that's already wired, unplug the 3V3 wire to the Heltec first. Close the mapper or any serial monitor, since only one program can hold the port.

3

Pick your station below and click Install

Choose the XIAO in the browser's port list. Tick Erase device the first time you install over other firmware. The page detects the chip (ESP32-S3, C3, C5 or C6) and installs the matching image.

4

Restart and check

Press R on the XIAO if it doesn't restart by itself. To watch it boot, click the same button again and choose Logs & Console: the boot banner lists the enabled detection layers, then a heartbeat follows every 60 s on a field station (30 s on a home station).

5

Wire it to a Heltec V4

XIAO D4 / GPIO5 (TX) to Heltec 47, D5 / GPIO6 (RX) to Heltec 48, GND to GND, and 3V3 to 3V3 on field stations only. Set the Heltec's Meshtastic serial module to TEXTMSG, 115200 baud, RX 47, TX 48. Full steps: Build a station and Set up the Heltec V4.

Level 2 networkfield + home stations

A typical deployment: Field station firmware on every detector out on a pole or roof, and Home station firmware on the XIAO plugged into the computer running mesh-mapper.py. Add as many field stations as you like. 

┌─────────────────────────────────────────────────────────────┐
│              FIELD STATION   (pole or roof, solar)          │
│  XIAO ESP32-S3 ──UART──> Heltec V4 (Meshtastic) ──LoRa──>   │
│  detects drones          GPIO5 TX ──> Heltec 47             │
│  over WiFi + BLE         GPIO6 RX <── Heltec 48             │
└─────────────────────────────────────────────────────────────┘
                               │
                        LoRa mesh network
                       (multiple hops OK)
                               │
┌─────────────────────────────────────────────────────────────┐
│              HOME STATION   (next to the mapper)            │
│  Heltec V4 (Meshtastic) ──UART──> XIAO ESP32-S3 ──USB──>    │
│  receives the mesh       Heltec 48 ──> GPIO6 RX   computer  │
│                          Heltec 47 <── GPIO5 TX   running   │
│  no detection            drops duplicates       the mapper  │
└─────────────────────────────────────────────────────────────┘

Why two firmwares: when five field stations hear the same drone, the mapper would otherwise get five copies of every detection. Each field station tags its reports with a node_id taken from its own MAC. The home station keys on the drone's MAC: the first report goes straight through, copies from other stations within 500 ms are dropped, and the next one after that goes through. Level 1 bearing reports always pass, because the mapper needs bearings from several stations to cross them.

[ STANDALONE ]

Standalone detector

One board plugged straight into the mapper's computer: every detection goes out USB as JSON. If a Heltec is wired up, it also posts a short text alert with map links to the mesh every 5 s, which any Meshtastic app can read but the mapper doesn't plot. Don't run several of these into one mapper; that's what field and home stations are for.

[ DUAL BAND ]

Dual-band detector

Adds the 5 GHz UNII-3 channels (149-165) that Remote ID may use, on top of 2.4 GHz WiFi and BLE. The ESP32-C5 covers both bands; on an ESP32-S3 the same firmware runs 2.4 GHz only.

Troubleshootingcommon snags
?

The XIAO isn't in the port list

Try another cable (charge-only cables are common). Then put the XIAO into bootloader mode: hold B, press and release R, release B, and click Install again. On Linux your user needs the dialout group (see the flashing steps).

?

"Your board is not supported"

That button has no image for the chip it found. A C3 only has the WiFi-only build, a C5 only the dual-band build, and a C6 only the standalone build.

?

The Heltec doesn't pass detections on

Check its serial module: serial.enabled true, serial.mode TEXTMSG, serial.baud BAUD_115200, serial.rxd 47, serial.txd 48. Every Heltec, field and home, must share the same primary channel and key.

?

The mapper shows duplicate detections

Several standalone detectors feed one mapper and nothing drops the copies. Flash the detectors as field stations and the board on the mapper as a home station.

?

No drone detections at all

Check the boot banner in Logs & Console first. Many drones broadcast no Remote ID, and DJI aircraft only do with the motors running. More in the README's No drone detections.
